# 🎬 CineBook – Movie Ticket Booking System

A simple, console-based Movie Ticket Booking System developed using Python and Object-Oriented Programming (OOP).

CineBook allows users to explore available movie shows, check seat availability, and book movie tickets.

## Features

- **View All Shows:** Display all available movies with their show IDs and timings.
- **View Available Seats:** Check available and booked seats for a particular show.
- **Book Tickets:** Select seats and book tickets.
- **Seat Validation:** Prevent invalid seat selections and duplicate bookings.
- **Ticket Details:** Display customer information, movie details, selected seats, and total ticket price.

## Technologies Used

- Python 
- Object-Oriented Programming (OOP)
- Python Lists and Dictionaries
- Conditional Statements and Loops
